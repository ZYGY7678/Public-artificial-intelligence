# AI Talk — מנוע שיחה מקומי זעיר ל-Qin 1S

יעד: Android API 19 / Android 4.4.4, מסך 240×320.

## מה נבנה
- מנוע שיחה מקומי בעברית, ללא אינטרנט וללא הורדת מודל בזמן ריצה.
- זיהוי כוונות בסיסי: ברכות, תודה, עזרה, זהות, שם המשתמש, שעה, תאריך, בדיחה ושאלות על יכולות האפליקציה.
- מחשבון מובנה לתרגילים פשוטים עם שני מספרים (+, -, *, /).
- זיכרון זמני של שם המשתמש בזמן שהאפליקציה פתוחה.
- אין ספריות חיצוניות, אין קובצי משקולות ואין שימוש בשרת. המנוע קטן מאוד וחוסך RAM ואחסון.

## מגבלה חשובה — לא LLM
זהו מנוע שיחה מבוסס כללים ותבניות, ולא מודל שפה גנרטיבי. הוא לא מאמן את עצמו, לא מבין כל ניסוח, ולא יכול לנהל שיחה פתוחה ברמה של ChatGPT. הבחירה הזאת מכוונת למגבלות החומרה המדווחות של Qin 1S: כ-256MB RAM ו-512MB אחסון כולל מערכת ההפעלה. מודל גנרטיבי עברי איכותי לא יכול להיות מובטח במכשיר הזה בלי למדוד זיכרון פנוי בפועל; מודלים נפוצים גדולים מדי למגבלות האלה.

## קול
זיהוי הדיבור והקראת הטקסט משתמשים בשירותי Android דרך המכשיר. הם אינם חלק ממנוע השיחה המקומי, וייתכן שיידרשו שירותים מותקנים או אינטרנט. תמיכה בקול עברי לא מובטחת בקושחה.

## בנייה
Gradle 6.7.1 + Android Gradle Plugin 4.2.2 + JDK 11; Android SDK platform 29/build-tools 29.0.3.
