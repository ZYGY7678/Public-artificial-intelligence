מה האתר עושה

האתר מאפשר למשתמש להתחבר עם חשבון Google וליצור מפתח API של Gemini בחשבון Google Cloud שלו. הפעולות מתבצעות בשם המשתמש ובאישורו.

הרשאות שהאתר מבקש

האתר מבקש גישה ל-Google Cloud (cloud-platform). ההרשאה משמשת רק לשלוש פעולות: יצירת פרויקט חדש, הפעלת Gemini API בפרויקט, ויצירת מפתח API המוגבל ל-Gemini. האתר לא קורא, משנה או מוחק שום משאב אחר בחשבון.

איזה מידע נאסף

האתר לא אוסף, לא שומר ולא שולח לשרת כלשהו שום מידע על המשתמש, כולל כתובת האימייל, אסימון ההרשאה והמפתח שנוצר. כל התהליך רץ בדפדפן של המשתמש, ומול שרתי Google בלבד. המפתח מוצג על המסך להעתקה ואינו נשמר.

שיתוף מידע עם צדדים שלישיים

האתר לא משתף מידע עם אף גורם. השימוש בנתוני משתמש מ-Google עומד בדרישות מדיניות הנתונים של Google API Services, כולל דרישות השימוש המוגבל.

ביטול הרשאה ומחיקה

אפשר לבטל את ההרשאה בכל עת בכתובת myaccount.google.com/permissions. את המפתח והפרויקט שנוצרו אפשר למחוק ב-Google Cloud Console.
