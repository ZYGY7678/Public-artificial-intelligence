מפתח Gemini בכמה צעדים

מתחברים לחשבון Google, והאתר יוצר עבורך פרויקט Google Cloud ומפתח API לשימוש עם Gemini.

למה צריך לאשר גישה לחשבון Google?

כדי ליצור את המפתח, האתר צריך לבצע פעולות בחשבון Google Cloud שלך: ליצור פרויקט חדש, להפעיל בו את Gemini API וליצור מפתח שמוגבל לשירות Gemini. האישור מאפשר ל-Google לזהות שאתה מרשה לבצע את הפעולות האלה.

חשוב לדעת: במסך Google עשויה להופיע הרשאת Google Cloud רחבה. הקוד באתר משתמש בה לצורך הפעולות שתוארו כאן, אבל כדאי לקרוא את מסך ההרשאות לפני שמאשרים.

אם מופיעה הודעה: "האפליקציה הזו לא אומתה על ידי Google"

המשמעות היא שתהליך האימות של האפליקציה מול Google עדיין לא הושלם. Google מציגה אזהרה משום שהיא עדיין לא בדקה ואישרה את האפליקציה לשימוש בהרשאות המבוקשות. האזהרה אינה הוכחה שהאתר מסוכן, אך גם אינה משהו שכדאי להתעלם ממנו.

  1. 1בדקו שהגעתם לאתר שהתכוונתם להשתמש בו ושהכתובת היא zygy-setup-html.vercel.app.
  2. 2אם אתם מכירים את האתר וסומכים על מפעיליו, לחצו על "מתקדם" (Advanced), אם האפשרות מופיעה.
  3. 3Google עשויה להציג קישור להמשך אל האפליקציה. המשיכו רק אם אתם מבינים את ההרשאה ומעוניינים לאפשר את הפעולות המפורטות.
  4. 4במסך ההרשאות עברו על מה ש-Google מבקשת. אם משהו לא ברור או לא תואם להסבר כאן — בחרו "ביטול" או חזרו לבטיחות.
אין חובה לאשר. אם אינכם בטוחים, אל תמשיכו ואל תמסרו הרשאה.
